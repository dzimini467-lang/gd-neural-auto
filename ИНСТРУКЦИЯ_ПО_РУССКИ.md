# GD Neural Auto v0.3: установка и использование

**В этом ZIP находится полный исходный проект, а не готовый мод `.geode`.**

## Загрузка проекта на GitHub

1. Распакуй архив. Не загружай сам ZIP в репозиторий.
2. Открой распакованную папку и выдели все файлы и папки ВНУТРИ, включая скрытую `.github`.
3. В GitHub открой репозиторий `gd-neural-auto`, нажми **Add file → Upload files**.
4. Перетащи содержимое папки, а не саму папку. Нажми **Commit changes**.
5. На главной странице GitHub проверь, что `CMakeLists.txt`, `mod.json`, `src/`, `.github/` находятся прямо в корне.
6. Проверь путь `.github/workflows/build.yml`. Если `.github` не загрузилась, создай файл через **Add file → Create new file** с именем `.github/workflows/build.yml` и вставь в него содержимое из архива.
7. Перейди в **Actions** и открой **Build GD Neural Auto (Windows)**. Если GitHub попросит разрешить Actions, подтверди.
8. После зелёной галочки скачай внизу страницы артефакт `gd-neural-auto-v0.3-win64`.
9. Распакуй артефакт и скопируй полученный `.geode` в `C:\Program Files (x86)\Steam\steamapps\common\Geometry Dash\geode\mods\`.
10. Перезапусти игру.

**Важно:** в старом репозитории на скриншоте были лишние папки `SRC/` и `gd_neural_auto_starter/`, а также ZIP. Лучше удалить их или создать новый чистый репозиторий, чтобы не путаться. Сборка использует корневой `src/`.

## Как обучать

- На уровне открой паузу, выбери **Record Demo**, перезапусти попытку и сыграй сам.
- Затем включи **Train AI**, перезапусти попытку и дай боту пробовать варианты.
- AI запоминает лучший по горизонтальному расстоянию набор нажатий для конкретного уровня.
- **Forget AI** сбрасывает сохранённую стратегию для текущего уровня.

**Честное ограничение:** алгоритм обучается методом проб и ошибок, это не глубокая нейросеть. Сложные уровни он может не пройти. Нормальные уровни с одиночным персонажем подходят лучше всего. Используй для экспериментов, а не для рейтинговых рекордов.

Проверка сборки по-настоящему пройдёт на GitHub Actions. Если появится красный крестик, открой неуспешный шаг и пришли текст ошибки.
